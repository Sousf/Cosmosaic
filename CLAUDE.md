### Objective

- Create a hyprland like tiling system for the mac
- This application should be installable via the apple app store
- Tiling should work just like hyprland, also add in the ability to switch focus in different windows as well similar to on linux.
- Allow user to create keybinding to launch applications, and switch window focus, etc.
- Feel free to suggest any other features, the more hyprland linux like experience the better.
